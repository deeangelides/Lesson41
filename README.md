# Lesson 41 — Diana Nyad: Never, Ever Give Up 🏊

Playful-Detective teaching pack: the true story of Diana Nyad's 110-mile swim from Cuba to Florida, a map of her route, comprehension, the perfect continuous tenses and a "Create Your Story" emoji writing game — then play ocean-themed games.

**Open `index.html`**, or publish this folder with GitHub Pages.

| File | What it is |
| --- | --- |
| `index.html` | Home page linking the lesson and every game |
| `lesson-41-diana-nyad.html` | The 28-slide lesson (arrow keys, thumbnail rail, ⛶ Present); Games Corner at the end |
| `ocean-connect-4.html`, `swim-word-search.html`, `feed-the-beach-cat.html`, `seashell-catch.html`, `whack-a-jellyfish.html`, `swim-to-florida.html`, `beach-shootout.html`, `memory-match.html` | 8 ocean-themed games |

Upload everything (including `nyad/`, `stickers/`, `cats/`, `fonts/`, `slides/` and `.nojekyll`). Keep file names exactly as they are. The route map loads map data from the internet, so it needs a connection.

Most photos in `nyad/` are from Wikimedia Commons; the swimming photos (`nyad-swim-1978`, `nyad-rescue-1978`, `nyad-jump-2011`, `nyad-cap-2012`, `nyad-wave-2013`) are news-agency photos for private classroom use only.
